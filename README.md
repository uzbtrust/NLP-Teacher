# NLP Teacher

O'zbek tilida NLP va katta til modellarini (LLM) o'rganishga yordam beruvchi loyihalar to'plami.

Maqsad — oddiy transformer arxitekturasidan zamonaviy chegaraviy (frontier) modellargacha bo'lgan yo'lni
o'zbek tilida, interaktiv va bosqichma-bosqich tushuntirish. Atamalar ataylab inglizcha qoldiriladi,
chunki o'quvchi keyinchalik ingliz tilidagi manbalar bilan ishlashi kerak bo'ladi.

## Loyihalar

| Loyiha | Tavsif | Holat |
|---|---|---|
| [Transformer-Explainer](./Transformer-Explainer) | Brauzerda haqiqiy GPT-2 modelini ishlatuvchi interaktiv vizualizatsiya | Ishlab chiqilmoqda |
| NLPwiki | 40 bo'limdan iborat NLP bilimlar bazasi (Obsidian formatida) | Keyinroq qo'shiladi |
